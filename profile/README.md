# HKUST-ELPA

**An open-source community for ELPA speaking preparation and resource sharing.**

HKUST-ELPA 是面向香港科技大学（HKUST）及香港科技大学（广州）（HKUST(GZ)）同学的非官方英语口语备考社区。我们整理考试指南、题库与备考经验，提供在线练习工具，也欢迎更多同学分享考试回忆和学习资源。

[访问网站](https://hkust-elpa.github.io/) · [考试指南](https://hkust-elpa.github.io/guide.html) · [题库练习](https://hkust-elpa.github.io/practice.html) · [投稿分享](https://hkust-elpa.github.io/submit.html) · [资料来源](https://hkust-elpa.github.io/sources.html)

## 备考资源

- **考试指南**：了解常规 ELPA 与 Fast Track 的流程及备考经验。
- **题库练习**：按校区、考试类型、场次和关键词筛选，支持随机抽题与计时练习。
- **学习记录**：标记掌握情况、整理笔记，并备份或恢复学习记录。
- **经验分享**：提交回忆题目、提示小问与备考经验，审核后加入社区资源。
- **资料来源**：查阅官方说明及社区整理的补充材料。

## 项目说明

基础设施由发起人提供支持。社区内容来自公开资料与同学分享，不代表香港科技大学或香港科技大学（广州）的官方立场。考试要求与安排请以学校当期通知为准。
